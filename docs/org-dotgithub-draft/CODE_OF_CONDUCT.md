# Code of Conduct

The Almanac adopts the [Contributor Covenant, version 2.1][covenant], in full and without
modification, as the code of conduct for every repository in this organization.

The canonical text is at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>. It is reproduced there in
its authoritative form; this file adopts it by reference so the two can never drift apart.

In short: participate in a way that would not embarrass you if quoted. Assume good faith,
disagree about the work rather than the person, and accept that maintainers may decline a
contribution without that being an insult.

## Scope

This applies in every space the organization controls — issues, pull requests, discussions,
commit messages, and code review across all repositories — and whenever someone is representing
the project in public.

Reports are handled confidentially. Whoever receives one will not act on a matter in which they
are personally involved; where that cannot be avoided, they will say so and hand it to someone
else.

## Enforcement

Maintainers may take any action they judge proportionate, including editing or removing
contributions, and temporary or permanent bans from the organization. The Contributor Covenant's
enforcement guidelines — correction, warning, temporary ban, permanent ban — describe the ladder
that is normally followed.

Anyone who disagrees with an enforcement decision may say so, once, in writing, to the same
contact. Reversal is possible; relitigation is not.

## A note on catalog disputes

Disagreements about *whether an entry is accurate* are not conduct matters — they are the
project working correctly. Contest them on the pull request with evidence: a URL, a status code,
a redirect chain, an archive capture. The catalog is meant to change its mind when the facts
say so.

Conduct enforcement covers how people treat each other, never whose reading of a dataset
prevailed.
