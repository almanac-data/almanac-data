# Funding (org default)

Org-level `.github/FUNDING.yml` shows the Sponsor button on every repo in the
org unless a repo ships its own file.

**Live destination:** GitHub Sponsors → `rudi193-cmd` (Stripe → personal bank).

```yaml
github: [rudi193-cmd]
```

Copy into `ORG/.github/FUNDING.yml` on the default branch.
